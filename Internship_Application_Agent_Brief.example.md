# Internship Application Agent Brief (template)
Copy to `Internship_Application_Agent_Brief.md` and fill in. Every agent reads this first; it overrides everything else.

1. Who I am: degree, graduation date, visa / work-authorization status.
2. Target term and dates (e.g. Summer 2027, May–Aug).
3. Target roles in priority order (Tier 1 / 2 / 3).
4. Locations in priority order.
5. Hard rules (e.g. never answer No to future sponsorship; never claim a certification I don't hold).
6. Companies to avoid and why.
7. Application history (company · role · date · status), so nothing is applied to twice.
8. Tone and length for cover letters and free-text answers.
